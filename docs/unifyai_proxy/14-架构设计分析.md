## 三、分层架构详解

### 3.1 应用层 (Application Layer)

**职责**: 处理 HTTP 请求/响应，实现 RESTful API

**核心组件**:

```go
// API Gateway
type Gateway struct {
    router      *Router
    middlewares []Middleware
    config      *Config
}

// Router
type Router struct {
    routes map[string]http.HandlerFunc
}

func (r *Router) Route(path string, handler http.HandlerFunc) {
    r.routes[path] = handler
}

// Middleware Chain
type Middleware func(http.Handler) http.Handler

func ChainMiddlewares(middlewares ...Middleware) Middleware {
    return func(next http.Handler) http.Handler {
        for i := len(middlewares) - 1; i >= 0; i-- {
            next = middlewares[i](next)
        }
        return next
    }
}
```

**中间件栈**:
```
请求 → CORS → 日志 → 认证 → 限流 → 处理器 → 响应
```

### 3.2 业务层 (Business Layer)

**职责**: 核心业务逻辑，协议转换，认证管理

#### 3.2.1 认证服务架构

```go
type AuthService struct {
    tokenManager  TokenManager
    oauthHandler  OAuthHandler
    storage       TokenStorage
    refreshPolicy RefreshPolicy
}

type TokenManager interface {
    GetValidToken(ctx context.Context, provider string) (*Token, error)
    RefreshToken(ctx context.Context, provider string) error
    RevokeToken(ctx context.Context, provider string) error
}

type RefreshPolicy interface {
    ShouldRefresh(token *Token) bool
    RefreshThreshold() time.Duration
}

// 默认策略: 提前 5 分钟刷新
type DefaultRefreshPolicy struct{}

func (p *DefaultRefreshPolicy) ShouldRefresh(token *Token) bool {
    return time.Now().After(token.ExpiresAt.Add(-5 * time.Minute))
}
```

#### 3.2.2 转换服务架构

```go
type TransformService struct {
    transformers map[string]Transformer
}

type Transformer interface {
    Name() string
    TransformRequest(req *OpenAIRequest) (interface{}, error)
    TransformResponse(resp interface{}) (*OpenAIResponse, error)
    TransformStreamEvent(event interface{}) (*OpenAIStreamChunk, error)
}

// 策略模式: 根据 Provider 选择对应的 Transformer
func (s *TransformService) GetTransformer(provider string) Transformer {
    return s.transformers[provider]
}

// 注册机制
func (s *TransformService) Register(t Transformer) {
    s.transformers[t.Name()] = t
}
```

**职责**: 提供技术基础设施支持

```go
// HTTP Client Pool
type HTTPClientPool struct {
    clients sync.Map  // provider -> *http.Client
}

func (p *HTTPClientPool) GetClient(provider string) *http.Client {
    client, ok := p.clients.Load(provider)
    if !ok {
        client = &http.Client{
            Timeout: 30 * time.Second,
            Transport: &http.Transport{
                MaxIdleConns:        100,
                MaxIdleConnsPerHost: 10,
                IdleConnTimeout:     90 * time.Second,
            },

        p.clients.Store(provider, client)
    }
    return client.(*http.Client)
}
```

## 五、项目特有关键决策（对齐配置与实现）

- 模型路由：支持模型别名/黑名单、force-model-prefix；映射前做能力校验（多模态/Tool Calling/上下文长度），不满足则拒绝或回退 preview 模型。
- Provider 扩展：除 OAuth 渠道外，需要支持 OpenAI-compatible upstream、Vertex/API-key 直连、Amp 路由（与配置中的 `openai-compatibility`/`vertex-api-key`/`ampcode` 保持一致）。
- 限额/状态机：按 `account-limits` 配置实现日请求/Token 上限与 RPM；状态为 Available/CoolingDown/QuotaExceeded/Errored，超额或限流后标记冷却，定时重置；所有账号不可用时统一返回 429/503，并暴露最近重置时间。
- 重试与切换：对 403/408/5xx/429 结合 `request-retry` 和 `max-retry-interval`；避免同账号自旋，切换路由策略（轮询/fill-first）。
- SSE 稳定性：支持 keepalive/首包重试，事件映射到 OpenAI delta，错误事件即时中断并输出统一错误。
- 安全与运维：TLS/反代、管理端远程开关与密钥哈希、日志脱敏与文件容量上限、health/metrics 暴露、日志采样；持久层权限 600，必要时对称加密 token。
- 配置驱动与热更新：限额/路由/代理/日志策略从配置加载；文件 watcher 更新时刷新映射/账号表/限额，避免打断已有 SSE/WS。

## 六、关键设计模式

### 6.1 策略模式 (Strategy Pattern)

**应用场景**: Provider 选择、协议转换

```go
// 策略接口
type Provider interface {
    SendRequest(ctx context.Context, req interface{}) (interface{}, error)
}

// 具体策略
type ClaudeProvider struct { /* ... */ }
type GeminiProvider struct { /* ... */ }

// 上下文
type ProviderContext struct {
    strategy Provider
}

func (c *ProviderContext) SetProvider(p Provider) {
    c.strategy = p
}

func (c *ProviderContext) ExecuteRequest(ctx context.Context, req interface{}) (interface{}, error) {
    return c.strategy.SendRequest(ctx, req)
}
```

### 6.2 工厂模式 (Factory Pattern)

**应用场景**: 创建 Provider 实例、Transformer 实例

```go
type ProviderFactory struct {
    tokenManager TokenManager
    httpClient   *http.Client
}

func (f *ProviderFactory) CreateProvider(name string) (Provider, error) {
    switch name {
    case "claude":
        return &ClaudeProvider{
            tokenManager: f.tokenManager,
            httpClient:   f.httpClient,
        }, nil
    case "gemini":
        return &GeminiProvider{
            tokenManager: f.tokenManager,
            httpClient:   f.httpClient,
        }, nil
    default:
        return nil, fmt.Errorf("unknown provider: %s", name)
    }
}
```

### 6.3 适配器模式 (Adapter Pattern)

**应用场景**: 将各 Provider 的 API 适配为统一接口

```go
// 目标接口 (OpenAI 格式)
type UnifiedRequest struct {
    Model    string
    Messages []Message
}

// Claude 原生格式
type ClaudeNativeRequest struct {
    Model    string
    System   string
    Messages []ClaudeMessage
}

// 适配器
type ClaudeAdapter struct{}

func (a *ClaudeAdapter) Adapt(unified *UnifiedRequest) *ClaudeNativeRequest {
    system, messages := extractSystem(unified.Messages)
    return &ClaudeNativeRequest{
        Model:    unified.Model,
        System:   system,
        Messages: convertMessages(messages),

```

### 6.4 观察者模式 (Observer Pattern)

**应用场景**: Metrics 收集、日志记录

```go
type Event struct {
    Type      string
    Provider  string
    Duration  time.Duration
    Error     error
}

type Observer interface {
    OnEvent(event *Event)
}

type EventPublisher struct {
    observers []Observer
}

func (p *EventPublisher) Subscribe(o Observer) {
    p.observers = append(p.observers, o)
}

func (p *EventPublisher) Publish(event *Event) {
    for _, observer := range p.observers {
        go observer.OnEvent(event)
    }
}

// Metrics Observer
type MetricsObserver struct {
    metrics *Metrics
}

func (o *MetricsObserver) OnEvent(event *Event) {
    o.metrics.RecordRequest(event.Provider, event.Duration, event.Error)
}
```

### 6.5 责任链模式 (Chain of Responsibility)

**应用场景**: 中间件处理

```go
type Middleware func(http.Handler) http.Handler

// 日志中间件
func LoggingMiddleware(logger *Logger) Middleware {
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            start := time.Now()
            next.ServeHTTP(w, r)
            logger.Info("Request processed", "duration", time.Since(start))
        })
    }
}

// 认证中间件
func AuthMiddleware(validator APIKeyValidator) Middleware {
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            apiKey := r.Header.Get("Authorization")
            if !validator.Validate(apiKey) {
                http.Error(w, "Unauthorized", 401)
                return
            }
            next.ServeHTTP(w, r)
        })
    }
}

// 链式组合
handler := LoggingMiddleware(logger)(
    AuthMiddleware(validator)(
        RateLimitMiddleware(limiter)(
            finalHandler,
        ),
    ),
)
```

### 7.2 关键并发控制

#### Token 刷新并发控制

```go
type TokenManager struct {
    tokens    sync.Map  // provider -> *Token
    refreshMu sync.Map  // provider -> *sync.Mutex
}

func (tm *TokenManager) GetValidToken(ctx context.Context, provider string) (*Token, error) {
    val, _ := tm.tokens.Load(provider)
    token := val.(*Token)
    
    if !needsRefresh(token) {
        return token, nil
    }
    
    // 获取该 Provider 的专属锁
    muVal, _ := tm.refreshMu.LoadOrStore(provider, &sync.Mutex{})
    mu := muVal.(*sync.Mutex)
    
    mu.Lock()
    defer mu.Unlock()
    
    // 双重检查
    val, _ = tm.tokens.Load(provider)
    token = val.(*Token)
    if !needsRefresh(token) {
        return token, nil
    }
    
    // 刷新
    newToken, err := tm.refreshToken(ctx, provider, token)
    if err != nil {
        return nil, err
    }
    
    tm.tokens.Store(provider, newToken)
    return newToken, nil
}
```

```go
type ConfigWatcher struct {

}

func (w *ConfigWatcher) Watch() {
    watcher, _ := fsnotify.NewWatcher()
    watcher.Add(w.configPath)
    
    for {
        select {
        case event := <-watcher.Events:
            if event.Op&fsnotify.Write == fsnotify.Write {
                newConfig := loadConfig(w.configPath)
                w.config.Store(newConfig)
                
                for _, listener := range w.listeners {
```

```go
type ConnectionPool struct {
    pools sync.Map  // provider -> *pool
}

type pool struct {
    client     *http.Client
    activeConns atomic.Int32
    maxConns    int32
}

func (p *ConnectionPool) GetClient(provider string) (*http.Client, error) {
    poolVal, _ := p.pools.LoadOrStore(provider, newPool())
    pool := poolVal.(*pool)
    
    if pool.activeConns.Load() >= pool.maxConns {
        return nil, errors.New("connection pool exhausted")
    }
    
    pool.activeConns.Add(1)
    return pool.client, nil
}

func (p *ConnectionPool) Release(provider string) {
    poolVal, ok := p.pools.Load(provider)
    if ok {
        pool := poolVal.(*pool)
        pool.activeConns.Add(-1)
    }
}
```

```go
type KeyManager struct {
    masterKey [32]byte
}

func (km *KeyManager) Encrypt(plaintext []byte) ([]byte, error) {
    var nonce [24]byte
    rand.Read(nonce[:])
    
    encrypted := secretbox.Seal(nonce[:], plaintext, &nonce, &km.masterKey)
    return encrypted, nil
}

func (km *KeyManager) Decrypt(ciphertext []byte) ([]byte, error) {
    var nonce [24]byte
    copy(nonce[:], ciphertext[:24])
    
    plaintext, ok := secretbox.Open(nil, ciphertext[24:], &nonce, &km.masterKey)
    if !ok {
        return nil, errors.New("decryption failed")
    }
    return plaintext, nil
}
```

## 十三、总结

### 核心架构原则

1. **分层清晰**: 应用层、业务层、基础层职责明确
2. **接口驱动**: 通过接口实现模块解耦
3. **并发安全**: 关键路径使用锁和原子操作保护
4. **可扩展性**: 插件化 Provider，支持水平扩展
5. **可观测性**: 完善的日志、指标、追踪体系
6. **安全第一**: 多层次安全防护
7. **性能优化**: 缓存、连接池、流式零拷贝

### 技术选型建议

| 组件 | 推荐技术 | 原因 |
|------|----------|------|
| 编程语言 | Go 1.21+ | 并发性能好，编译后单文件部署 |
| HTTP 框架 | 标准库 net/http | 简单稳定，性能足够 |
| 配置格式 | YAML | 人类可读，支持注释 |
| 日志库 | zerolog | 高性能结构化日志 |
| Metrics | Prometheus | 事实标准 |
| 缓存 | sync.Map / Redis | 单机/分布式 |
| 加密 | NaCl secretbox | 简单安全 |
