# 任务 B：认证、账户、配额与调度

前置：完成 `15-任务拆解-基础设计.md`（冲突以 15 为准）；依赖任务 A 的配置/日志接口。

## 目标
- 完成 OAuth 登录/刷新/存储，账户表状态机，配额/限额与调度策略。

## 范围
- OAuth 管理：登录/本地回调/PKCE、刷新、凭证存储（文件、权限 600，可选加密）、Token 脱敏日志。
- 账户状态机：Available/CoolingDown/QuotaExceeded/Errored，含 `UnavailableUntil`/`ResetAt`。
- 限额：按 `account-limits` 实现日请求/Token、RPM；定时重置；超额/限流标记与冷却；全账号不可用时的 429/503。
- 选路与切换：轮询/fill-first，避免同账号自旋；对 403/408/429/5xx 结合 `request-retry`/`max-retry-interval`；预览模型回退与 `quota-exceeded` 选项对齐。
- Rate limiter：每账号 limiter，配置驱动；避免阻塞生产者（可用缓冲 channel 或权重信号）。
- 观测：账户状态/限额相关 metrics 钩子，占位记录。

## 交付物
- 包/文件：`internal/auth`（oauth/login/refresh/storage），`internal/account` 或 `internal/quota`（状态机、selector、limiter、reset 任务）。
- 公共接口：AccountSelector、RateLimiter/QuotaCounter、TokenStore；暴露给任务 C 的选路与 token 获取接口。
- 自测：并发获取 token 的双重检查刷新；限额触发后的切换；全账号不可用时的错误。
- 验收标准：
  - **账户状态机**: 四状态（Available/CoolingDown/QuotaExceeded/Errored）正确转换；状态转换加锁保护；ResetAt/UnavailableUntil 字段正确计算。
  - **限额管理**: `account-limits` 配置驱动日请求/Token/RPM 限额；超限时状态转换为 QuotaExceeded；RPM 使用滑动窗口；定时重置任务正确触发。
  - **重试与切换**: 对 403/408/429/5xx 按 `request-retry` 重试；单账号不自旋；切换策略（round-robin/fill-first）生效；遵循 `quota-exceeded` 配置。
  - **全账号不可用错误响应**（遵循 15 决策和任务 A 格式）：
    - **429 返回体**（所有账户因配额耗尽不可用）：
      ```json
      {
        "error": {
          "message": "All accounts quota exceeded. Reset at 2025-12-31T00:00:00Z",
          "type": "rate_limit_error",
          "code": "quota_exceeded"
        }
      }
      ```
      HTTP 头：`Retry-After: <最近账户的 resetAt 时间戳>`
    - **503 返回体**（所有账户因错误/冷却不可用）：
      ```json
      {
        "error": {
          "message": "All accounts temporarily unavailable",
          "type": "server_error",
          "code": "service_unavailable"
        }
      }
      ```
      HTTP 头：`Retry-After: 60`
  - **Token 刷新**: 并发刷新使用双重检查锁定，避免闭包陷阱；刷新成功后重新获取账户引用。
  - **日志脱敏**: OAuth token 仅记录前8后4字符；client_secret/code_verifier 完全掩码。
  - **观测性指标**（补充任务 A 基础指标）：
    - `account_state{provider,state}` - 各状态账户数量
    - `account_quota_usage{provider,type}` - 配额使用情况（requests/tokens/rpm）
    - `account_state_transitions_total{provider,from,to}` - 状态转换计数
    - `oauth_token_refresh_total{provider,status}` - Token 刷新次数（成功/失败）
    - `account_selection_duration_seconds` - 账户选择延迟

## 依赖/接口契约
- 必须消费的配置字段（见 15/04）：`auth-dir`、`auth.providers`、`account-limits`、`routing`、`quota-exceeded`、`request-retry`、`max-retry-interval`、`streaming`、模型映射/黑名单、代理配置。
- 使用任务 A 的配置读取/日志/metrics 入口；遵循 `15` 的安全/观测决策；向任务 C 提供 AccountSelector/Token 获取接口。
