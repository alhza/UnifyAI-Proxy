# 任务 A：网关、配置与安全基线

前置：完成 `15-任务拆解-基础设计.md`（若与其他文档冲突，以 15 为准）。

## 目标
- 建立 HTTP/WS 网关与中间件栈，落地配置加载与管理端安全。
- 提供健康检查/metrics/管理端口的基础能力。

## 范围
- 路由与中间件：请求日志、错误恢复、CORS、超时、客户端 API Key 验证；可选 WS 认证占位。
- 配置系统：YAML+env 覆盖，配置校验；`remote-management`、`tls`、`logging-to-file`、`logs-max-total-size-mb`、`commercial-mode`、`proxy-url`、`routing`、`quota-exceeded`、`streaming`、`account-limits` 等字段解析。
- 管理端与安全：管理端远程开关、密钥哈希、面板开关、静态资源托管路径；TLS/反代兼容；日志脱敏（禁止 token 输出）。
- 观测性基础：/health、/metrics（接口占位），request log 采样开关。

## 交付物
- 包/文件结构：`internal/proxy`（server/router/middleware），`internal/config`（loader/validation），`internal/logging`（request log 工厂、文件滚动占位）、`internal/metrics` 占位。
- 初版配置解析与校验代码（含默认值）。
- 管理端路由与密钥校验逻辑；TLS/反代说明。
- 自测方案：curl 访问 /health；API Key 校验路径；管理端访问控制。
- 验收标准：
  - **配置解析**: 所有配置字段（见 15 对照表）正确解析并应用默认值；热更新触发配置重载；解析失败时保持当前配置并记录错误。
  - **错误响应格式**: 所有错误响应遵循 OpenAI 兼容格式：
    ```json
    {
      "error": {
        "message": "具体错误描述",
        "type": "invalid_request_error|authentication_error|rate_limit_error|server_error",
        "code": "错误代码（如 quota_exceeded）"
      }
    }
    ```
  - **HTTP 状态码与错误类型映射**：
    - 400: invalid_request_error（请求格式错误、缺失必填字段）
    - 401: authentication_error（API Key 无效或缺失）
    - 403: permission_error（权限不足）
    - 404: not_found_error（路由或模型不存在）
    - 429: rate_limit_error（配额耗尽），必须包含 `Retry-After` 头
    - 503: service_unavailable（所有账户不可用），必须包含 `Retry-After: 60` 头
    - 500/502/504: server_error（内部错误或上游故障）
  - **管理端安全**: 远程开关生效；secret-key 使用 bcrypt 哈希存储；未授权访问返回 401；面板禁用开关生效。
  - **健康检查**: `/health` 返回 200 + `{"status":"ok"}`；`/metrics` 返回 Prometheus 格式指标（至少包含占位符）。
  - **日志脱敏**: 请求日志中 access_token/refresh_token 仅显示前8后4字符；Authorization 头完全掩码；敏感配置字段不输出。
  - **观测性指标**（必备 Prometheus metrics）：
    - `http_requests_total{method,path,status}` - 请求计数
    - `http_request_duration_seconds{method,path,status}` - 请求延迟直方图
    - `http_requests_in_flight` - 当前并发请求数
    - `config_reload_total{status}` - 配置重载次数（成功/失败）
    - `log_entries_total{level}` - 日志条数（按级别）
  - **路由挂载点**: 提供注册接口供 B/C 挂载业务路由；支持中间件链（认证/日志/metrics/恢复）。

## 依赖/接口契约
- 必须消费的配置字段（见 15/04）：`server`、`tls`、`remote-management`、`auth.providers`、`logging`、`logging-to-file`、`logs-max-total-size-mb`、`commercial-mode`、`proxy-url`、`routing`、`quota-exceeded`、`streaming`、`account-limits`。
- 按 `15` 的安全/观测决策：管理端远程开关+密钥哈希、日志脱敏、health/metrics 占位、日志采样。
- 给子任务 B 提供配置与日志接口（logger/metrics 句柄），给子任务 C 提供路由挂载点与 request logging/metrics 注入点。
