## 三、核心数据结构

### 3.1 配置结构

```go
type Config struct {
    Server   ServerConfig   `yaml:"server"`
    Auth     AuthConfig     `yaml:"auth"`
    Quota    QuotaConfig    `yaml:"quota"`
    Mapping  MappingConfig  `yaml:"model-mapping"`
    Logging  LoggingConfig  `yaml:"logging"`
}

type ServerConfig struct {
    Host        string `yaml:"host"`
    Port        int    `yaml:"port"`
    AllowRemote bool   `yaml:"allow-remote"`
    SecretKey   string `yaml:"secret-key"`
}

type AuthConfig struct {
    Providers []AuthProvider `yaml:"providers"`
}

type AuthProvider struct {
    Type    string   `yaml:"type"`
    APIKeys []string `yaml:"api-keys,omitempty"`
}

type QuotaConfig struct {
    SwitchProject bool `yaml:"switch-project"`
    RetryCount    int  `yaml:"retry-count"`
}

type MappingConfig map[string]string
```

### 3.2 Token 结构

```go
type Token struct {
    AccessToken  string    `json:"access_token"`
    RefreshToken string    `json:"refresh_token"`
    ExpiresAt    time.Time `json:"expires_at"`
    TokenType    string    `json:"token_type"`
    Scopes       []string  `json:"scopes,omitempty"`
}

type Account struct {
    ID          string    `json:"id"`
    Provider    string    `json:"provider"`
    Token       *Token    `json:"token"`
    IsAvailable bool      `json:"is_available"`
    UnavailableUntil time.Time `json:"unavailable_until,omitempty"`
}
```

### 3.3 请求/响应结构

```go
// OpenAI 格式（统一入口）
type OpenAIRequest struct {
    Model       string          `json:"model"`
    Messages    []OpenAIMessage `json:"messages"`
    MaxTokens   int             `json:"max_tokens,omitempty"`
    Temperature float64         `json:"temperature,omitempty"`
    TopP        float64         `json:"top_p,omitempty"`
    Stream      bool            `json:"stream,omitempty"`
    Stop        []string        `json:"stop,omitempty"`
    Tools       []OpenAITool    `json:"tools,omitempty"`
    ToolChoice  interface{}     `json:"tool_choice,omitempty"`
}

type OpenAIMessage struct {
    Role       string           `json:"role"`
    Content    interface{}      `json:"content"` // string 或 []ContentPart
    ToolCalls  []OpenAIToolCall `json:"tool_calls,omitempty"`
    ToolCallID string           `json:"tool_call_id,omitempty"`
}

type OpenAIResponse struct {
    ID      string         `json:"id"`
    Object  string         `json:"object"`
    Created int64          `json:"created"`
    Model   string         `json:"model"`
    Choices []OpenAIChoice `json:"choices"`
    Usage   *OpenAIUsage   `json:"usage,omitempty"`
}
```

## 四、关键接口定义

### 4.1 Provider 接口

```go
type Provider interface {
    // 基本信息
    Name() string
    SupportedModels() []string
    
    // 认证
    Login(ctx context.Context) (*Token, error)
    GetToken() (*Token, error)
    RefreshToken() error
    
    // 请求
    SendRequest(ctx context.Context, req *ProviderRequest) (*ProviderResponse, error)
    StreamRequest(ctx context.Context, req *ProviderRequest) (<-chan *StreamEvent, error)
}
```

### 4.2 Transformer 接口

```go
type Transformer interface {
    // 请求转换
    TransformRequest(openaiReq *OpenAIRequest) (interface{}, error)
    
    // 响应转换
    TransformResponse(providerResp interface{}) (*OpenAIResponse, error)
    
    // 流式事件转换
    TransformStreamEvent(event interface{}) (*OpenAIStreamChunk, error)
    
    // 工具转换
    TransformTools(tools []OpenAITool) (interface{}, error)
    TransformToolChoice(choice interface{}) (interface{}, error)
}
```

### 4.3 TokenManager 接口

```go
type TokenManager interface {
    // Token 操作
    GetToken(provider string) (*Token, error)
    SaveToken(provider string, token *Token) error
    RefreshToken(provider string) error
    DeleteToken(provider string) error
    
    // 账户管理
    ListAccounts(provider string) ([]*Account, error)
    GetNextAvailableAccount(provider string) (*Account, error)
    MarkAccountUnavailable(provider string, accountID string, until time.Time) error
}
```

## 五、测试策略

### 5.1 单元测试

```go
// 转换测试示例
func TestConvertOpenAIToClaude(t *testing.T) {
    openaiReq := &OpenAIRequest{
        Model: "gpt-4",
        Messages: []OpenAIMessage{
            {Role: "system", Content: "You are helpful"},
            {Role: "user", Content: "Hello"},
        },
        MaxTokens: 1000,
    }
    
    claudeReq := ConvertOpenAIToClaude(openaiReq)
    
    assert.Equal(t, "claude-sonnet-4-5-20250929", claudeReq.Model)
    assert.Equal(t, "You are helpful", claudeReq.System)
    assert.Len(t, claudeReq.Messages, 1)
    assert.Equal(t, "user", claudeReq.Messages[0].Role)
}
```

### 5.2 集成测试

```go
func TestEndToEndClaude(t *testing.T) {
    // 启动测试服务器
    server := setupTestServer()
    defer server.Close()
    
    // 发送 OpenAI 格式请求
    resp, err := http.Post(
        server.URL+"/v1/chat/completions",
        "application/json",
        strings.NewReader(`{
            "model": "gpt-4",
            "messages": [{"role": "user", "content": "Hello"}]
        }`),
    )
    
    assert.NoError(t, err)
    assert.Equal(t, 200, resp.StatusCode)
    
    // 验证响应格式
    var openaiResp OpenAIResponse
    json.NewDecoder(resp.Body).Decode(&openaiResp)
    assert.NotEmpty(t, openaiResp.Choices)
}
```

## 六、部署配置

### 6.1 Docker

```dockerfile
FROM golang:1.21-alpine AS builder
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -o unifyai-proxy ./cmd/main.go

FROM alpine:latest
RUN apk --no-cache add ca-certificates
WORKDIR /app
COPY --from=builder /app/unifyai-proxy .
COPY config.yaml.example config.yaml
EXPOSE 8317
CMD ["./unifyai-proxy"]
```

### 6.2 Docker Compose


## 八、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| OAuth 端点变更 | 登录失败 | 配置化端点，快速更新 |
| API 格式变更 | 转换失败 | 版本检测，兼容层 |
| Token 泄露 | 账户被盗 | 加密存储，权限控制 |
| 账户封禁 | 服务中断 | 多账户备份，合规使用 |
| 速率限制 | 请求失败 | 智能限流，账户轮换 |
